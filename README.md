# Pub Heinähattu — website demo

Demo website for Pub Heinähattu, Vaasankatu 23, Helsinki.
Single-file static site (index.html) with inline CSS and JS, Google Fonts, EN/FI toggle via data-en/data-fi attributes, sticky mobile action bar (call / WhatsApp / directions).

Preview locally: run `python -m http.server 8000` in this folder and open http://localhost:8000
